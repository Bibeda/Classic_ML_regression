# Прогнозирование стоимости бриллиантов

Проект по решению задачи **регрессии**: предсказание цены бриллианта на основе его физических характеристик и категорий качества. 

## 1. Постановка задачи

**Целевая переменная:** `price` - стоимость бриллианта в долларах США.

Исходный датасет содержит **53 940 наблюдений** и **10 колонок**, включая целевую переменную (то есть **9 признаков**).

| Признак | Описание | Значения / диапазон |
|---|---|---|
| `price` | Цена бриллианта, USD (**таргет**) | 326–18 823 |
| `carat` | Масса бриллианта в каратах | 0.20–5.01 |
| `cut` | Качество огранки | Fair, Good, Very Good, Premium, Ideal |
| `color` | Цвет: от J (ниже качество) до D (выше качество) | J, I, H, G, F, E, D |
| `clarity` | Чистота: наличие внутренних включений и внешних дефектов | I1, SI2, SI1, VS2, VS1, VVS2, VVS1, IF |
| `x` | Длина, мм | 0–10.74 |
| `y` | Ширина, мм | 0–58.9 |
| `z` | Высота, мм | 0–31.8 |
| `depth` | Относительная глубина, %: `200 * z / (x + y)` | 43–79 |
| `table` | Относительная ширина верхней площадки, % | 43–95 |

Для оценки используются:

- **MAE** - средняя абсолютная ошибка в долларах; отражает типичную величину отклонения прогноза.
- **RMSE** - корень из среднеквадратичной ошибки в долларах;
- **R²** - показывает качество модели относительно предсказания константы=среднее значение таргета.

## 2. Разведочный анализ и предобработка

### Очистка данных

Пропущенных значений обнаружено не было. На этапе подготовки данных:

1. Удалён технический столбец `Unnamed: 0`.
2. Удалены полностью повторяющиеся записи.
3. Исключены наблюдения с нулевой длиной, шириной или высотой (`x`, `y`, `z`): такие размеры физически невозможны.
4. Проверена согласованность записанного `depth` с расчётным значением `200 * z / (x + y)`. Наблюдения, для которых абсолютное отклонение превышало 1 были исключены.

После очистки осталось 53695 наблюдений.

### Основные наблюдения EDA

1. **Масса и размеры связаны:** Распределения `carat`, `x`, `y`, `z` имеют несколько локальных пиков. При разбиении бриллиантов на группы по массе распределения размеров меняются: более тяжёлым камням, как правило, соответствуют большие линейные размеры, что довольно логично.

2. У таргета (цена) и такими признаками как вес камня, размеры камня очень высокая корреляция.

3. **Разброс цен растёт вместе с массой:** На графике `price` от `carat` у более крупных камней заметно выше дисперсия цены. Это указывает на возможную гетероскедастичность, которую стоит отдельно проверить при анализе остатков модели.

4. **Взаимосвязь категориальных признаков с ценой и весом бриллианта.** Были построены графики зависимости `price` от `carat` с разбиением по категориям `clarity`, `cut` и `color`. Для `clarity` обнаружены заметные различия в характере роста стоимости: у бриллиантов с низкой чистотой (I1) зависимость относительно пологая, тогда как у бриллиантов с высокой чистотой (IF) цена растёт значительно быстрее с увеличением веса.
Для `cut` и `color` аналогичной чёткой закономерности на графиках обнаружено не было. Влияние этих признаков на характер зависимости цены от веса визуально выражено слабее.

5. **Влияние огранки и цвета не так легко изолировать.** Для `cut` и `color` на аналогичных графиках ценовые диапазоны категорий существенно перекрываются. Отсутствие строгого порядка цен на графике не означает отсутствия порядка качества: цена одновременно зависит от массы, чистоты и других характеристик.

6. **Связи нелинейны.** Зависимости `price` от `carat` и геометрических размеров визуально напоминают степенные; аналогичная нелинейность наблюдается между `carat` и `x`, `y`, `z`.

7. **Глубина связана с типом огранки.** Значения `depth` для `Premium` и `Ideal` сосредоточены в более узких диапазонах, особенно для `Premium`; среди крайних значений чаще встречается `Fair`.

### Подготовка признаков

- **Категориальные признаки** (`cut`, `color`, `clarity`) преобразованы с помощью `OrdinalEncoder` в порядке возрастания качества.
- **Числовые признаки** (`carat`, `depth`, `table`, `x`, `y`, `z`) не были изменены.

стандартизированы с помощью `StandardScaler` для единообразия предобработки и сопоставимости масштабов. Для деревьев решений и ансамблей на их основе стандартизация обычно не требуется; для линейной регрессии без регуляризации она также не является обязательной.

## 3. Базовые модели

В работе были обучены `LinearRegression`, `DecisionTreeRegressor`, `RandomForestRegressor` и `LGBMRegressor`.

Результаты на тестовой выборке:

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| DummyRegressor | 3002.78 | 3950.56 | −0.00 |
| LinearRegression | 779.48 | 1186.80 | 0.91 |
| DecisionTreeRegressor | 353.34 | 718.31 | 0.97 |
| RandomForestRegressor | **264.86** | 533.04 | 0.98 |
| LGBMRegressor | 275.82 | **521.62** | **0.98** |

Как можно видеть нелинейные модели значительно превосходят линейную регрессию. `RandomForestRegressor` достигает минимального MAE, а `LGBMRegressor` показывает лучшие RMSE и R².

## 4. Улучшения и Feature Engineering

Для проверки полезности новых признаков использована 5-блочная кросс-валидация. Каждый эксперимент сравнивался с исходной моделью без дополнительных признаков.

### 4.1. Объём бриллианта

Добавлен признак `volume = x * y * z` - приближённая характеристика объёма, вычисленная по габаритам камня.

Результат оказался смешанным: линейная регрессия улучшилась (MAE снизилась примерно на **8.98 $**, RMSE - на **9.68 $**), но для ансамблевых моделей эффект был небольшим и неоднозначным. У LightGBM MAE немного уменьшилась, тогда как RMSE выросла.

### 4.2. Квадрат массы

Добавлен признак `carat_squared = carat ** 2`, чтобы явно представить нелинейную зависимость стоимости от массы.

Наиболее заметный эффект получен для линейной регрессии: **MAE уменьшилась примерно на 7.98 $, RMSE - на 41.01 $**. Для дерева и ансамблей изменения были минимальными: эти модели уже способны учитывать нелинейные зависимости без явного возведения признака в квадрат.

### 4.3. Отношение массы к произведению размеров

Добавлен признак `density_proxy = carat / (x * y * z)`.

Добавление признака слегка снизило ошибки линейной регрессии, случайного леса и LightGBM. Например, у LightGBM MAE уменьшилась примерно на **1.39 $**, RMSE - на **1.83 $**. Для одиночного дерева качество, наоборот, ухудшилось (RMSE выросла примерно на **7.97 $**). Возможная причина - изменение выбранных разбиений дерева после добавления признака.

<br>
<br>

**Промежуточный вывод:** ни один из трёх признаков не обеспечил существенного и устойчивого улучшения всех моделей. Наибольший эффект от явных нелинейных преобразований наблюдался у линейной регрессии.

## 4.4. Анализ ошибок модели

При анализе остатков модели LightGBM была обнаружена выраженная гетероскедастичность: с увеличением реальной стоимости бриллиантов растёт разброс ошибок предсказания.

Для уменьшения зависимости величины ошибок от стоимости бриллиантов было применено логарифмическое преобразование целевой переменной (`log(price)`). После обучения предсказания возвращались в исходный масштаб с помощью экспоненты.


## 5. Подбор гиперпараметров

Для дальнейшего улучшения качества предсказаний был проведён подбор гиперпараметров модели LightGBM, которая ранее показала наилучший результат по RMSE.

### 5.1. RandomizedSearchCV

Для поиска оптимальных гиперпараметров использовался `RandomizedSearchCV` с 5-блочной кросс-валидацией.

В качестве функции оценки использовалась MSE. Всего было проверено 100 случайных комбинаций гиперпараметров, что составило 500 обучений модели.

**Пространство поиска:**

| Гиперпараметр | Значения |
|---|---|
| `n_estimators` | 200, 300, 500, 700, 1000 |
| `learning_rate` | 0.01, 0.03, 0.05, 0.07, 0.1 |
| `num_leaves` | 15, 31, 63, 127 |
| `max_depth` | 4, 6, 8, 10, 12, -1 |
| `min_child_samples` | 5, 10, 20, 40, 80 |
| `reg_lambda` | 0, 0.1, 1, 5, 10 |

**Лучшие найденные гиперпараметры:**

| Гиперпараметр | Оптимальное значение |
|---|---:|
| `n_estimators` | 500 |
| `learning_rate` | 0.03 |
| `num_leaves` | 127 |
| `max_depth` | 6 |
| `min_child_samples` | 5 |
| `reg_lambda` | 0.1 |

### Результаты

После подбора гиперпараметров модель была повторно обучена на тренировочной выборке и оценена на тестовых данных.

Изменение метрик относительно исходной модели:

| Метрика | Изменение |
|---|---:|
| MAE | −13.50 |
| RMSE | −12.66 |
| R² | +0.00083 |

Подбор гиперпараметров позволил улучшить все три метрики. В частности, RMSE снизилась на 12.66 доллара, а MAE — на 13.50 доллара.
